# Wokanda — strona aplikacji

Kod strony Wokandy (menedżer zadań i projektów). **W tym repozytorium nie ma żadnych danych** — wszystkie dane są szyfrowane w przeglądarce (AES-256-GCM, klucz z hasła głównego znanego tylko właścicielowi) i przechowywane na osobnym serwerze wyłącznie jako szyfrogramy.

Repozytorium jest generowane automatycznie z prywatnego repozytorium aplikacji — nie edytuj plików ręcznie.
